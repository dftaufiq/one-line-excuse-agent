A one-line excuse an AI agent gives its human after missing a deadline: the agent read a 9 AM deadline as a suggestion, then a rumor, then history. The program writes the line (77 characters) to `/output/entry.txt` for the make.fun judge to compare pairwise against other entries.

## Run it

```sh
python3 main.py
```
